# gikai-map-hokkaido

北海道内の市町村議会情報を横断的に収集・整理する情報サイト。

## 概要

各市町村議会のウェブサイトから議会情報を自動収集し、横断的に閲覧・比較できる形で公開することを目的としています。

**収集対象情報**
- 議員名簿
- 議決結果
- 議会だより
- 行事予定

## ディレクトリ構成

```
gikai-map-hokkaido/
├── scraper/
│   └── chitose/       # 千歳市議会スクレイピングスクリプト
├── data/              # 収集済みJSONデータ
└── site/              # フロントエンド（今後）
```

## 技術スタック

|------|------|
