# note下書き: 北海道の地方議会情報を、もっと探しやすくしたい

## タイトル案

北海道の地方議会情報を、もっと探しやすくしたい

## 本文

北海道の市町村議会では、毎回の定例会や委員会で、暮らしに近いテーマがたくさん議論されています。

除雪、学校給食、公共交通、防災、子育て、空き家、観光、地域医療。どれも住民にとって身近なテーマです。

ただ、その議論をあとから探そうとすると、意外と大変です。

議事録は各自治体の公式サイトに公開されていますが、自治体ごとにページ構成も検索方法も違います。PDFで公開されているもの、会議名から探す必要があるもの、古い記録が別ページに分かれているものもあります。

そこで、北海道内の市町村議会情報を横断して探せる非公式サイトとして「地方議会ドットコム」を作っています。

現在は、北海道内の市町村議会と北海道議会について、議員情報、議事録、議決結果などを少しずつ整理しています。すべての自治体が同じ機能に対応しているわけではありませんが、対応範囲を広げながら、まずは「情報の入口」として使いやすい形を目指しています。

このサイトでやりたいことは、議会の情報を置き換えることではありません。

大事なのは、原典にたどり着きやすくすることです。

検索や記事で関心のあるテーマを見つけ、そこから公式議事録やPDFに戻って確認できる。市民が地域の議論を知る入口を、少しでも低くしたいと考えています。

今後は、よい議会質問をした議員へのインタビューや、質問の背景を紹介する読みものも増やしていく予定です。議事録だけでは見えにくい、質問に至るまでの問題意識や現場の声も、市民に届く形で残していきたいです。

もし、紹介したい議会質問や、取り上げてほしい地域課題があれば教えてください。

北海道の地方議会で交わされている大事な議論を、もっと見つけやすく、もっと読まれやすくしていきます。
