# 更新情報運用メモ

トップページの「更新情報」と `/news` は `site/data/news.json` を単一の真実源として表示する。

## いつ追記するか

- 機能追加
- 改善
- 修正
- 自治体追加
- 利用者に知らせるべき重要なお知らせ

原則として、関連実装と同じ変更単位で `site/data/news.json` に追記する。

## どう追記するか

手で `site/data/news.json` を編集してもよいが、形式を崩さないために次のスクリプト利用を推奨する。

```bash
node scripts/add-news-item.mjs \
  --date 2026-05-03 \
  --category 改善 \
  --title "タイトル" \
  --body "本文"
```

使えるカテゴリ:

- `機能追加`
- `改善`
- `修正`
- `お知らせ`
- `自治体追加`

## 文面の方針

- 利用者に伝わる言葉で書く
- 実装詳細より「何が変わったか」を優先する
- 誇張しない
- 日付は `YYYY-MM-DD`

## 確認ポイント

- `site/data/news.json` が JSON として壊れていない
- トップページの更新情報一覧に表示される
- `/news` の時系列表示でも崩れない
