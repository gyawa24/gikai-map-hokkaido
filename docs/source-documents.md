# 千歳市公開資料RAG PoC 対象資料候補

作成日: 2026-05-09

この文書は、千歳市公開資料RAG PoCで最初に投入する資料候補を整理する。実装・AWSデプロイ・資料ダウンロードはまだ行わない。

## 基本方針

- 最初から資料を増やしすぎない。初回投入は10〜20件に絞る。
- 千歳市公式サイト、千歳市議会の公開情報、地方議会ドットコム上の公開議事録データなど、公開確認できる資料だけを使う。
- 個人情報、相談記録、非公開資料、内部メモは入れない。
- 回答に根拠資料リンクを出せるよう、投入資料には必ず `source_url` を付ける。
- PDF全文一括が大きい場合は、概要版または章別PDFを優先する。
- 画像PDFやスキャンPDFは初回から無理に入れない。

## 優先度の考え方

| 優先度 | 意味 | 初回投入 |
|---|---|---|
| A | 一般質問・政策調査で横断的に使いやすく、根拠性も高い基幹資料 | 入れる |
| B | 特定テーマの質問に有用。Aの結果を見て追加する資料 | 原則あとで |
| C | 参考にはなるが、分量・形式・更新頻度・個人情報リスクの面で初回向きではない資料 | 初回除外 |

## 優先度C

初回PoCでは入れない。

| 優先 | 資料 | 除外理由 |
|---|---|---|
| C | 市民相談、陳情対応メモ、メール、LINE、議員個人のメモ | 非公開・個人情報リスクが高い |
| C | 名簿中心の資料 | 個人情報・不要な個人属性を含みやすい |
| C | 農業委員会など個別審議会の議事録 | 公開資料でも個人情報配慮が必要。初回は避ける |
| C | 都市計画図・地図PDF | 画像・図面中心でRAG引用が不安定になりやすい |
| C | 予算書全文一括88MBなど大型PDF | 初回には重すぎる。概要・大綱・説明資料を優先 |
| C | 古い計画の過年度版 | 最新資料との混同が起きやすい。比較目的ができてから |
| C | イベント告知・募集記事・短期のお知らせ | 政策調査の根拠としては寿命が短い |

## 形式ごとの注意点

### PDF

- 1ファイル50MB以下を目安にする。
- 全文一括より、章別・概要版・説明資料を優先する。
- PDF内にページ番号があるか確認する。
- スキャンPDFや画像中心PDFは、初回では除外する。
- 表が多い資料は、表の読み取り崩れが起きないか重点評価する。
- 同名の `.metadata.json` に `file_name`、`url`、`year`、`category`、`department` を付ける。

### HTML

- 市公式ページ本文は軽量で扱いやすい。
- ただし、ページ本文が概要だけでPDF本体が別にある場合は、HTMLとPDFのどちらを根拠にするか明確にする。
- ナビゲーション、問い合わせ先、広告的な共通部分を取り込みすぎない。

### 議事録

- 既に `data/chitose/minutes/` に千歳市議会の公開議事録データがある。
- 初回PoCでは行政計画資料と議事録を混ぜすぎない。
- 議事録を入れる場合は、年度・会議名・発言者・発言URLをメタデータ化する。
- 議事録は「市の公式見解」ではなく「議会での発言・答弁」として扱う。
- 発言者名は公開情報だが、RAG回答では個人攻撃や政治的評価に使わない。

### Excel / CSV

- 予算・統計などの表形式資料に有用。
- RAGでは表構造が崩れることがあるため、初回はPDF説明資料またはHTMLを優先する。
- 必要なら後段でMarkdownまたはCSVに整形して投入する。

## 初回投入案

まずは以下の10件程度に絞る。

1. 第7期総合計画 基本構想 概要版または章別PDF
2. 第7期総合計画 実施計画の最新版
3. 教育振興基本計画 全体版
4. 千歳市こども計画 本体または概要版
5. 地域防災計画 目次
6. 地域防災計画 地震災害対策編
7. 地域防災計画 風水害等対策編
8. 地球温暖化対策実行計画 概要版または本編
9. 地域公共交通計画
10. 令和7年度予算編成説明資料または予算大綱

## 投入前チェック

- 公開URLがある
- 取得日を記録した
- 年度・所管部署・カテゴリを記録した
- 個人情報が主目的の資料ではない
- ファイルサイズが大きすぎない
- 画像中心PDFではない
- 回答時に引用リンクとして出せる
- 古い資料と新しい資料が混在する場合、年度をメタデータ化した
