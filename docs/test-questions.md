# 千歳市公開資料RAG PoC テスト質問

作成日: 2026-05-09

この文書は、RAG回答の品質を検証するための質問セットを定義する。質問は「根拠資料付きで答えさせる」ことを基本とし、一般質問づくりに使えるものも含める。

## 使い方

- すべての質問で「根拠資料名・URL・可能ならページ番号」を回答に含めさせる。
- 回答が資料にない場合は「資料内では確認できません」と言えるか確認する。
- 原文確認なしで議会質問や発信に使わない。
- 個人情報や非公開情報は質問に含めない。
- 1回目は `n_queries=2`、`output_in_detail=false` を基本にする。
