# 検索データ整理方針

作成日: 2026-06-16

地方議会ドットコムの検索品質は、検索アルゴリズムだけで上げない。
先に「検索されるデータ」を、原文・構造化・市民向けテーマ・検索用索引に分ける。

## 目的

市民が自然に入力する語句から、該当する議員・会議・質問テーマ・公式議事録へ到達できる状態を作る。

例:

- `小川 陽平 スケート学習`
- `除雪 千歳`
- `学校給食 今井`
- `部活動 地域移行`

## データを4層に分ける

### 1. 原文層

公式議事録、速報、動画、議決結果、PDFなどの原本情報。

守ること:

- 発言内容を改変しない。
- 出典URL、取得日、会議名、日付、自治体slugを持つ。
- AI要約や市民向けテーマを原文として扱わない。

主な場所:

- `data/{slug}/minutes/`
- `data/{slug}/segments/`
- `site/data/{slug}/minutes/`
- `site/data/{slug}/segments/`

### 2. 構造化層

誰が、いつ、どの会議で、何を質問し、誰が答弁したかを扱う層。

まずは次の粒度を目指す。

| 粒度 | 役割 |
|---|---|
| `turn` | 発言単位。話者、役職、質問/答弁、原文位置を持つ |
| `question_block` | 議員ごとの質問まとまり |
| `topic_block` | 論点ごとの質問・答弁まとまり |
| `member_activity` | 議員詳細・テーマページ・検索に使う公開向け活動要約 |

守ること:

- `topic_snippets` は原文の部分文字列として検証できること。
- 議員名寄せは曖昧な場合に無理につなげない。
- 質問と答弁の対応が不確実なものは、確定データとして扱わない。

参考:

- `docs/editorial/structured-minutes-rollout.md`
- `docs/editorial/ebetsu-turns-prototype.md`

### 3. 市民向けテーマ層

市民が検索しそうな言葉へ整える層。

例:

- `スケート学習`
- `部活動の地域移行`
- `学校給食`
- `除雪・排雪`
- `千歳駅前の路面凍結`

守ること:

- 原文の発言断片をそのままテーマ名にしない。
- 1テーマは短く、名詞句を基本にする。
- 同じ意味の表記は寄せる。
- 原文リンクへ戻れる構造を維持する。

避ける例:

- `ありがとうございます。最後の質問になるのですけども`
- `、中項目１、部活動の地域移行について`
- `この事業の予算額は１１０万円ほどとなっておりましたが`

### 4. 検索用索引層

検索画面とAPIが読む派生データ。

守ること:

- 検索のためだけに原文や活動データを改変しない。
- 市町村で絞った検索は、市町村別の軽い索引を読む。
- 検索品質は正解台帳で確認する。

主な場所:

- `site/public/generated/search-index.json`
- `site/public/generated/search-indexes/{slug}.json`
- `site/data/search_quality_cases.json`

## 当面の進め方

### Step 1: 千歳市で正解台帳を育てる

`site/data/search_quality_cases.json` に、期待する検索語と期待結果を置く。

最初の対象:

- 小川陽平議員の `スケート学習`
- 小川陽平議員の `除雪`
- 小川陽平議員の `学校給食`

確認:

```bash
cd site
npm run build-search-index
npm run check:search-quality
```

### Step 2: テーマ名の品質を上げる

`members_activity.json` の `summary_topics` を、発言断片ではなく市民向けテーマへ寄せる。

優先順位:

1. 千歳市
2. 恵庭市
3. 苫小牧市
4. 活動データが多い自治体

### Step 3: 質問・答弁単位へ進む

構造化議事録ビューで使っている `turns` / `question_blocks` / `topic_blocks` を、検索データの正規化にも使う。

ただし、全市町村に一気に広げない。
まずは公式HTMLやPDFの話者見出しが安定している自治体だけに限定する。

### Step 4: 検索画面を再設計する

データが整ってから、検索画面を次の入口に分ける。

- 議員を探す
- 質問テーマを探す
- 公式議事録を探す
- 速報を探す
- 議決結果を探す

## 完了条件

この方向の作業は、見た目を直しただけでは完了にしない。

- `npm run check:search-quality` が通る。
- 期待する検索語で、期待する会議・議員・テーマへ到達できる。
- 原文リンクが残っている。
- `site/data/news.json` への反映要否を確認している。
- 新しく増やしたテーマ名が、市民向けの短い名詞句になっている。
