# 構造化議事録ビュー 展開メモ

更新日: 2026-05-13

## 現在の方針

- まず「公式PDF/HTMLから発言見出しを安定して抽出できる会議録」を対象にする。
- 表示本文は原文を使い、要約や言い換えを混ぜない。
- 各発言・論点には公式ページへのリンクを出す。
- 生成後は `npm run validate:structured-minutes` で、topic_snippets が turns の原文部分文字列であることを検証する。
- データ量が大きくなるため、町村側は一括生成せず、自治体単位または数会議録単位で増やす。

## 判断メモ

白老町のように1会議録あたり発言数が多い自治体は、表示側のページ送りが必須。構造化JSONも大きくなるため、全候補を一気に追加するより、抽出精度とデータ量を確認しながら段階的に広げる。

生成後に見るべき点:

- 議員質問と市町村側答弁が同じ question block に入っているか
- 公式リンクが各 snippet に出ているか
- タイトルが「○○議員の質問」だけになりすぎていないか
- 長い会議録でも `/turns?view=topics&page=2` 以降が重すぎないか
