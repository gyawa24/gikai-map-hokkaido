# 地方議員の質問の型 実例集

作成日: 2026-05-12
状態: 編集メモ

## このメモの使い方

`local-council-question-patterns.md` で整理した質問の型に、実際の議事録ソースを対応させた実例集。

目的は、抽象的な「良い質問論」ではなく、どの質問がどんな答弁を引き出したのかを、記事化・研修・質問作成支援に使える形で残すこと。

## 型1: 方針確認型

### 具体例: 恵庭市 まだ誘致方針を決めているのか

質問の要点:

- 市長は報道機関には前向きなコメントをしている。
- しかし、市民や議会には公式の場で誘致方針を明らかにしていないのではないか。
- 誘致を進めるのか、財政負担や経済効果をどう考えるのか。

引き出された答弁:

- 球団の具体的な構想や場所が明らかではない。
- 現段階では、誘致する・しないとは答えられない。
- ファイターズ側から具体的な動きがあれば、市として歓迎し、できる限り対応する考えはある。

この質問の効き方:

報道コメントと議会での公式答弁の差を確認している。行政が「まだ決めていない」と言える範囲を明確にしたうえで、将来の歓迎姿勢も引き出している。

出典:

- 質問: `data/eniwa/segments/235.json` / `eniwa-235-3-096`
- 市長答弁: `data/eniwa/segments/235.json` / `eniwa-235-3-097`
- 市長再答弁: `data/eniwa/segments/235.json` / `eniwa-235-3-131`
- 部長答弁: `data/eniwa/segments/235.json` / `eniwa-235-3-137`

## 型2: 情報公開・説明責任型

### 具体例: 苫小牧市 球団とのコンタクトはあるのか

質問の要点:

- 北海道日本ハムファイターズ2軍施設の誘致について、市はどのように取り組んでいるのか。
- 球団とのコンタクトはあるのか。
- 現状を市民に説明できる範囲で確認したい。

引き出された答弁:

- 2024年の報道以降、球団関係者と複数回情報交換を実施。
- 2025年7月7日の球団発表後にも、球団関係者と意見交換。
- 球団が求める内容や新たな拠点の考え方を聞いている。
- アクセス面と一定程度の用地確保が論点になっている。

この質問の効き方:

「誘致したいですか」ではなく、「具体的に接触しているのか」と聞いているため、行政内部の動きが表に出た。読者にとっては、ただの期待論なのか、実務的な情報交換が始まっているのかを見分ける材料になる。

出典:

- 質問: `data/tomakomai/segments/284.json` / `tomakomai-284-2-017`
- 答弁: `data/tomakomai/segments/284.json` / `tomakomai-284-2-018`

## 型3: 財政負担確認型

### 具体例: 千歳市 建設費と行政負担をどう見るか

質問の要点:

- 2軍球場、寮、室内練習場などの整備が必要になる。
- 公設民営の場合、建設費は数十億円から100億円とも言われる。
- 千歳市として費用の見通しは立つのか。
- 他にも次世代半導体産業など多くの選択肢がある中で、この構想に参画できるのか。

引き出された答弁:

- 移転が実現すれば、スポーツコミュニティー形成や地域経済活性化につながる。
- 一方で、市街地周辺での適地確保など難しい課題が多い。
- 鎌ケ谷の2軍本拠地に匹敵する土地を千歳市で用意するには大きな課題がある。
- 今後も、千歳市として何ができるか球団側と対話する。

この質問の効き方:

効果だけでなく、費用と土地の制約を同時に問うている。結果として、市長・企画部長から「期待はあるが、現実には大きな課題がある」という慎重な答弁を引き出している。

出典:

- 質問: `data/chitose/segments/555.json` / `chitose-555-4-018`
- 市長答弁: `data/chitose/segments/555.json` / `chitose-555-4-019`
- 企画部長答弁: `data/chitose/segments/555.json` / `chitose-555-4-021`

## 型4: 土地・場所確認型

### 具体例: 江別市 旧江別小学校跡地・飛烏山公園を使えるか

質問の要点:

- JR江別駅周辺地域の再開発を進める必要がある。
- 旧江別小学校跡地や飛烏山公園などを活用し、ファーム施設誘致を駅周辺活性化に生かせないか。
- 球団へ早期に誘致の意向を発信すべきではないか。

引き出された答弁:

- 誘致が実現すれば、持続可能な都市運営、観光、スポーツ振興、子どもたちにとって魅力的なコンテンツになる。
- 球団側とは担当者が面談やメールで情報収集している。
- 移転が決定した場合に直ちに具体的協議を進められるよう、用地や財源確保策などについて庁内検討チームを設置している。

この質問の効き方:

「誘致したい」ではなく、「どの土地をどう使うか」を問うことで、用地・財源・庁内体制の話まで答弁を進めている。

出典:

- 質問: `data/ebetsu/segments/20241004.json` / `ebetsu-20241004-4-064`
- 市長答弁: `data/ebetsu/segments/20241004.json` / `ebetsu-20241004-4-065`

## 型5: 地域資源接続型

### 具体例: 旭川市 スタルヒン球場・花咲スポーツ公園と接続する

質問の要点:

- 日ハム2軍本拠地移転構想と、旭川市の花咲スポーツ公園再整備構想はタイミングも内容も合うのではないか。
- 旭川市にはスタルヒン球場があり、新たに100億円規模の球場を用意しなくても再整備で対応できる可能性がある。
- 屋内施設、商業施設、親子ゲームが可能な移動時間などを含め、観光・スポーツ振興の新たな挑戦として考えられないか。

引き出された答弁:

- 市民が日常的にスポーツを楽しむ機会、子どもたちの夢、地域経済振興など幅広い効果が期待できる。
- 一方で、球場や選手寮などは自治体が建設し、多額の費用がかかる。
- 北広島市からの距離も重視されているとの報道がある。
- それでもチャンスはあると捉え、球団との関係を深め、あらゆる可能性を排除せず前向きに検討する。
- 花咲スポーツ公園の価値創出とも接続して検討している。

この質問の効き方:

単発の誘致ではなく、既存施設、都市再整備、スポーツ、観光、子どもの遊び場、健康づくりを一つの政策群としてつないでいる。答弁も「費用は重いが、地域資源と結びつけて検討する」という形になっている。

出典:

- 質問: `data/asahikawa/segments/300.json` / `asahikawa-300-5-246`
- 市長答弁: `data/asahikawa/segments/300.json` / `asahikawa-300-5-247`

## 型6: 市民合意・機運確認型

### 具体例: 恵庭市 約5万筆の署名をどう受け止めるか

質問の要点:

- 恵庭市日本ハムファイターズ新ファーム施設誘致期成会から署名提出があった。
- 署名数は4万9,916筆。
- 市長として、その思いをどう受け止めているのか。
- 市民全体の誘致への意識をどう捉えているのか。

引き出された答弁:

- 約5万筆という大きな数字に驚き、活動を重く受け止めている。
- 市民の熱い思いを、球団との意見交換の場で伝えたい。
- 運動・スポーツ推進計画に関わるアンケートや市民意識調査でも、5割から6割程度が誘致を期待している。
- 地域の盛り上がり、期待、熱意、本気度をアピールしながら積極的に進めたい。

この質問の効き方:

署名という市民アクションを、行政の公式答弁に載せている。これにより、誘致が行政だけの判断ではなく、市民機運を伴うテーマとして記録される。

出典:

- 質問: `data/eniwa/segments/253.json` / `eniwa-253-3-048`
- 市長答弁: `data/eniwa/segments/253.json` / `eniwa-253-3-049`
- 市民意識への答弁: `data/eniwa/segments/253.json` / `eniwa-253-3-051`

## 型7: 比較・ベンチマーク型

### 具体例: 岩見沢市 6市と比べて何が不利か

質問・答弁の要点:

- 岩見沢市は、球団が情報交換している6市には入っていない。
- しかし、市の担当職員を球団に派遣し、球団幹部と情報交換している。
- 球団側は、新千歳空港とエスコンフィールドへのアクセスを重視している。
- 1軍・2軍拠点間、選手、ファンの移動でも公共交通が重要と聞いている。
- その比較上、岩見沢市は新千歳空港やエスコンへの公共交通アクセスで条件的に不利と認識している。

この質問の効き方:

誘致への熱意を問うだけではなく、他自治体との比較条件を引き出している。結果として「なぜ岩見沢は不利なのか」が、公共交通アクセスという具体条件で説明された。

出典:

- 市長答弁: `data/iwamizawa/segments/764.json` / `iwamizawa-764-3-005`

メモ:

- このセグメントは再質問への答弁で、質問本文の分割が粗い。記事化時は該当会議録本文で前後文脈を再確認する。

## 型8: 実行体制確認型

### 具体例: 苫小牧市 2軍誘致担当を設置するのか

質問の要点:

- ファーム施設誘致に対する市長の決意を問う。
- 苫小牧商工会議所を中心に発足する期成会とどう連携するのか。
- 胆振地域全体で機運を高めることが重要ではないか。
- 市長はどうリーダーシップを取るのか。

引き出された答弁:

- 球団と情報交換を重ねる。
- 苫小牧商工会議所を中心に発足する期成会と連携する。
- 東胆振地域が一体となって誘致機運を高める。
- 誘致実現に向け、2025年10月1日から北海道日本ハムファイターズ2軍誘致担当を設置予定。

この質問の効き方:

市長の気持ちだけでなく、実行体制まで確認している。結果として、担当設置という具体的な行政アクションが答弁に出た。

出典:

- 質問: `data/tomakomai/segments/284.json` / `tomakomai-284-2-021`
- 市長答弁: `data/tomakomai/segments/284.json` / `tomakomai-284-2-022`

## 型9: リスク確認型

### 具体例: 北広島市 既存ボールパーク都市として追加負担をどう見るか

質問・答弁の要点:

- ファーム本拠地が道内移転した場合の経済波及効果や交流人口増への期待がある。
- 一方で、公設民営型への対応や市財政の状況を考えると、北広島市が積極的に動くことは現実的ではないのではないか、という問題提起がある。
- 市長は、Fビレッジがあるまちとして北海道移転は喜ばしいとしつつ、ファーム施設がまちづくりにどのような価値を生むのか、財政負担も含めて慎重に進める必要があると答弁。
- 交通対策についても、ファイターズや警察など関係機関との連携を説明している。

この質問の効き方:

経済効果だけを見ず、財政負担、交通、既存ボールパーク効果の市民還元まで含めて問うている。既に大型施設を持つ自治体ならではのリスク認識が出ている。

出典:

- 市長答弁: `data/kitahiroshima/segments/528.json` / `kitahiroshima-528-5-392`
- 議員の問題提起: `data/kitahiroshima/segments/528.json` / `kitahiroshima-528-5-395`

## 型10: 代替案提示型

### 具体例: 小樽市 ファイターズ2軍ではなく夏季合宿誘致へ

質問の要点:

- ファイターズ2軍誘致は大きな公費負担があり、小樽市では難しい。
- しかし、スポーツを通じた交流人口や経済効果を狙うことはできる。
- Jリーグなどの夏季合宿誘致なら可能性があるのではないか。

引き出された答弁:

- 平成25年度にプロサッカーチームが小樽市望洋サッカー・ラグビー場を5日間のミニキャンプで利用した実績がある。
- 北海道は陸上、ラグビー、サッカーなど様々な競技の合宿地として注目されている。
- 小樽市では、夏季合宿受入れの可能性がある競技について情報収集や他自治体との情報交換をしている。
- 夏季合宿誘致は、地域スポーツのレベルアップや経済効果が期待できるため、積極的に取り組む。

この質問の効き方:

本命案が難しいときに、政策目的を残したまま手段を変えている。大型誘致が無理でも、スポーツ政策として何ができるかを行政に答えさせている。

出典:

- 質問: `data/otaru/segments/20251004.json` / `otaru-20251004-1-110`
- 教育長答弁: `data/otaru/segments/20251004.json` / `otaru-20251004-1-112`

## 記事化メモ

この記事にするときは、各型を「議員向けノウハウ」にしすぎないほうがよい。

地方議会ドットコムらしくするなら、主語は「市民が議事録を読むと、良い質問の構造が見える」に置く。

締めの方向:

> 良い質問は、行政を追及するだけではない。行政が持っている情報、まだ決めていないこと、重視している条件、できない理由、次に動く体制を、市民の前に出す。議事録を読む面白さは、そこにある。
