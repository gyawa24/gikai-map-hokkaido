２．一般会計予算の内容
（１）一般会計予算の主な施策
１．安心できるまちづくり
 ① ０・１・２歳児の保育料軽減
       ０・１・２歳児の保育料軽減                         ( 歳入 △ 1,827万円 )
       保育料を一律10％引き下げるとともに市独自の多子軽減を実施
                                              ( 歳出 1,069万円 )

       保育士・幼稚園教諭奨学金返済支援事業                             342万円
       市内の保育所・幼稚園等に就業する保育士・幼稚園教諭を対象とした奨学金返済支援制度
       ・助成額： 上限額 月2万円・年間24万円
       ・助成期間： 最大5年間（雇用後5年以内）


 ② スクール児童館の無償化
       スクール児童館の利用者負担金無償化                      ( 歳入 △ 734万円 )
       スクール児童館を利用する登録児童の利用料（延長利用料を含む）を無償化


       スクール児童館開設時間の拡大                                 105万円
       土曜日・長期休業等におけるスクール児童館の開設時間を拡大
       ・延長開設時間（7：30～8：00）を設定


 ③ 多子世帯等の学校給食費を無償化
       第３子以降の学校給食費無償化                         ( 歳入 △ 707万円 )
       同一世帯内で18歳までのこどもから数えて第3子以降の給食費を原則無償化



 ④ 高校生までの子ども医療費助成の拡充
       子ども医療費助成                                   1億3,742万円
        助成対象年齢を15歳までから18歳までに引き上げるとともに、課税世帯   ( うち拡大分 7,401万円 )
       であっても助成対象とし、保護者の所得額要件を廃止


 ⑤ ふるさと室蘭に誇りを持つ教育環境整備と学力向上への取り組み
|拡充|   部活動の地域展開（室蘭市主体の地域クラブの設置）                      1,778万円
        部員数が少なく単独校での活動が困難な種目で、かつ中学生の受け皿となる
       民間主体のチームが整備されていない場合については、休日の活動の場として、
       室蘭市が主体となって地域クラブを設置

       ※ 休日の学校部活動は、令和13年度末（改革実行期間）までに
        全て民間主体の地域クラブ活動へ展開

       ・ 令和8年度： サッカー、野球

       コミュニティスクール支援事業                                 273万円
        学校と地域との連携を強化、学校運営協議会をサポートするため、各地区にコーディネーター
       を配置

       「室蘭ふるさと学習」推進事業                                1,606万円
       地域の人々や自然、産業に触れ合い、様々な体験活動を通して、ふるさと室蘭への愛着を育む
